1. Thứ tự thực hiện (không có ngoặc)

  • • Bước 1: Lũy thừa
  • • Bước 2: Nhân, chia (trái → phải)
  • • Bước 3: Cộng, trừ (trái → phải)
  • • VD: $5 + 3 \times 2^2 = 5 + 12 = 17$

2. Thứ tự thực hiện (có ngoặc)

  • • Tính trong ngoặc trước
  • • Nhiều ngoặc: ( ) → [ ] → { }
  • • VD: $50 - (3 \times 4) = 50 - 12 = 38$

3. Quy tắc bỏ ngoặc (+)

  • • Trước ngoặc là "+": giữ dấu
  • • $a + (b - c) = a + b - c$
  • • VD: $35 + (18 - 7) = 35 + 18 - 7 = 46$

4. Quy tắc bỏ ngoặc (−)

  • • Trước ngoặc là "−": đổi dấu
  • • $a - (b - c) = a - b + c$
  • • VD: $35 - (18 - 7) = 35 - 18 + 7 = 24$
